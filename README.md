## SEO Keyword Tool
This tool is created to do organize workflows for keyword research for a discounts & coupons platform.


### Features
* Automatic Google Sheets Syncing & Formatting
* Prompt Generation with Human-in-the-Loop AI integration
* SERPApi integration for competitor research to identify competitor blog content structure
<br><br>
### Google Sheets Integration Setup

To enable Google Sheets syncing, you need a Google Cloud Service Account.

1. Create Google Cloud Project
- Go to https://console.cloud.google.com
- Create a new project
2. Enable APIs
- Google Sheets API
- Google Drive API

3. Create Service Account
- Go to APIs & Services → Credentials
- Click Create Credentials → Service Account
- Create and finish setup

5. Generate Service Account Key
- Open the service account
- Go to Keys → Add Key → Create New Key
- Choose JSON
- Download the file

7. Share Google Sheet
- Create a Google Sheet: https://sheets.google.com
- Copy client_email from the JSON file
- Share the sheet with this email (Editor access)

8. Connect in App
- Paste the Service Account JSON into the tool
- Paste the Google Sheet URL
- Save / Test connection

-------------
Notes:<br>
Missing permissions usually means the sheet wasn’t shared with the service account.<br>
Ensure both Sheets API + Drive API are enabled.
<br><br>
 
### Tool Guide
1. Upload Semrush and/or Google Keyword Planner export data without any changes.
The tool will automatically process it.
- Note: For GKP, export historical metrics csv, not plan forecasts
2. Paste prompts that the tool shows into an AI tool and paste the JSON output only back into the tool.
3. Sync to Google Sheets.
- NOTE: Before syncing the new output to Google Sheets, remember to delete the old tabs.
As good practice, keep an empty tab for the Google Sheets always. The next two tabs are the output generated by the tool.
Delete these tabs once you're done copying data from it, before you sync and re-run for the next topic.
